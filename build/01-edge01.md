### Build EDGE01 (VyOS in VMware)

EDGE01 connects the lab network to the internet using NAT.

A VyOS VM was created: 
- choose "Other Linux 6.x kernel 64-bit" and attach the VyOS ISO.
  
- Give it NIC1 = NAT and NIC2 = VMnet10. 
  
- Boot it, log in as `vyos`/`vyos`, and run `install image`. Then detach the ISO and reboot.

After reboot type the follow commands: 

```
vyos@vyos:~$ show interfaces          # confirm eth0 (NAT) and eth1 (VMnet10); match MACs to VMware if unsure
vyos@vyos:~$ configure
vyos# set system host-name EDGE01
vyos# set interfaces ethernet eth0 address dhcp                     # WAN: VMware NAT gives it internet
vyos# set interfaces ethernet eth1 address 10.10.10.254/24          # LAN: gateway for the corp network
vyos# set nat source rule 100 outbound-interface name eth0          # masquerade corp traffic leaving eth0
vyos# set nat source rule 100 source address 10.10.10.0/24
vyos# set nat source rule 100 translation address masquerade
vyos# set system name-server 1.1.1.1                                # the router's own DNS resolver
vyos# set service ssh listen-address 10.10.10.254                   # SSH reachable from the LAN side only
vyos# commit ; save                                                 # apply the candidate config, then persist it
vyos# exit
vyos@EDGE01:~$ ping 1.1.1.1 count 3                                 # verify internet access
```
Use the `show interfaces` command to check config or see each interface role at a glance. 

A VyOS details to know:
- VyOS never "applies immediately": `commit` makes a change live, and `save` makes it survive a reboot.
